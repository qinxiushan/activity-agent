## 5. 遗留问题与阶段 2 建议

### 代码级待改进

1. **EventAdapter 未注入 planState phase 到事件中**
   - 当前 SSE 事件中没有 `currentPhase` 字段，前端 useActivitySession 需要独立轮询 plan-state
   - 建议：EventAdapter 在每个 StandardEvent 中注入 `phase` 字段

2. **Extension 的 BUSINESS_TOOLS 集合硬编码**
   - `phase-guard.ts` 和 `activity-tools.ts` 各有各的工具列表
   - 建议：从 `TOOL_METADATA` 读取，或抽成共享常量

3. **AgentSessionWrapper 的 `hasFiredDone` 重置方式是副作用**
   - 在 `agent_start` case 中重置状态标志是副作用模式
   - 建议：每个 prompt 创建新的 EventAdapter 实例

### 阶段 2 建议优先级

| # | 主题 | 原因 |
|---|------|------|
| 1 | PostgreSQL + 持久化 | 文件存储跨节点不可共享，生产部署前提 |
| 2 | Redis + 速率限制 | 多用户安全前置 |
| 3 | NextAuth + 用户隔离 | 生产多租户基础 |
| 4 | Docker + docker-compose | 环境一致性 |
| 5 | Grafana 仪表盘 | 可视化阶段 1 采集的 4 个 metric |
| 6 | Security Guard (25 检查点全量) | 安全纵深补全 |
